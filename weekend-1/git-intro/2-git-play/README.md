# The Git play

The story of the Git animation, played by the two of you on your own two laptops: a small
car-rental program on GitHub that you clone, change, commit, push and pull. One push is refused,
Git merges two changes by itself, and one change conflicts with the other's. Five acts and an
encore, about 40 minutes.

## What you need

- A partner. Decide who is Partner A and who is Partner B.
- Each of you: a laptop with VS Code and Git (the install party), and a GitHub account, free at
  https://github.com/signup. A needs B's GitHub username.
- The guide, `git-play.pdf` in this folder. Print it, or open it beside VS Code: on GitHub, click
  it in this folder; on your laptop, double-click it in Finder (Mac) or File Explorer (Windows).

## Where you play

The program is in the template repository https://github.com/sef-hs26/git-together. In Act 1, A
makes a private copy of it for the two of you, and both of you clone that copy. Clone it into a
folder of its own, such as `Documents`: a clone inside your `activities` folder would put one
repository inside another.

When your screen differs from the guide, look at its last page, Help, or ask a TA.
