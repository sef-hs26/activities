# The Git animation

The Git story of Friday's lecture, as a page for your browser. Carlos and Marcel build a small
shop program together through GitLab: they clone it, commit, push and pull. One push is refused,
and one change conflicts with the other's.

## Open it

In your browser: https://sef-hs26.github.io/activities/weekend-1/git-intro/1-git-animation/

Without internet: in your `activities` folder, open `weekend-1/git-intro/1-git-animation` in
Finder (Mac) or File Explorer (Windows) and double-click `index.html`. It opens in your browser.

From VS Code: in the Explorer, right-click `index.html` and choose **Reveal in Finder** (Mac) or
**Reveal in File Explorer** (Windows), then double-click it there.

## Keys

| Key | What it does |
|---|---|
| Right, Space or PageDown | next step |
| Left or PageUp | step back |
| Home, End | first step, last step |
| f | full screen |
| ? | the list of keys |

The two arrows below the narrator do the same as Right and Left.

## Free play

Click **Free play** at the top right. It starts from the step you are on, and the buttons on the
left act for Carlos and for Marcel: **Edit total.py**, **Edit receipt.py**, **git commit**,
**git push**, **git pull**, and in a conflict **Keep mine** or **Keep theirs**. For example, let
both edit the same file and commit, then let both push. **Undo** takes back the last button,
**Reset** takes back all of them, and **Story** returns to the story.
